# Data Cleaning & Reporting Automation Using Python

## 📌 Project Overview

This project demonstrates an automated data cleaning and reporting workflow using Python and Jupyter Notebook.

The project works with a sales dataset containing common data-quality issues such as missing values, duplicate records, inconsistent text, invalid dates, and incorrect numeric values.

The goal is to transform raw data into a clean, structured dataset and automatically generate useful business reports.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* OpenPyXL
* Microsoft Excel

## 🧹 Data Cleaning Performed

The project handles:

* Missing values
* Duplicate records
* Inconsistent region names
* Inconsistent product names
* Inconsistent payment methods
* Invalid dates
* Negative quantities
* Negative sales values
* Numeric values stored as text
* Incorrect data types

## 📊 Analysis Performed

The cleaned dataset is used to generate:

* Total Sales
* Total Orders
* Total Quantity Sold
* Average Sales
* Sales by Region
* Sales by Product
* Sales by Customer
* Monthly Sales

## 📈 Visualizations

The project generates visual summaries including:

* Sales by Region
* Sales by Product
* Monthly Sales Trend
